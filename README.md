# Полина Гусева — портфолио (верстка)

Статичная адаптивная верстка лендинга-портфолио. Исходник — экспорт из Tilda, переписан на чистые HTML/CSS/JS без зависимостей.
Контакты из второго экспорта собраны как футер страницы.

## Структура
- `index.html` — страница
- `css/style.css` — стили и адаптив (брейкпоинты 1100 / 900 / 700 / 420 px)
- `js/main.js` — меню, шапка, раскрытие услуг, переворот карточек, автоплей видео
- `fonts/`, `images/`, `videos/` — ассеты (шрифты Moniqa, Vasek, Source Code Pro)

## Шум
Анимированный `noise.gif` из Tilda убран. Вместо него — статичный лёгкий шум: SVG-фильтр `feTurbulence` в `body::after` (`css/style.css`).
Интенсивность — последнее значение `.26` в `feColorMatrix`.

## Запуск
Открыть `index.html` или поднять любой статичный сервер, например `python -m http.server`.
